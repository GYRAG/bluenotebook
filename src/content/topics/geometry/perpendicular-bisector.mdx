<Definition>**მანძილი** წერტილიდან წრფემდე ამ წერტილიდან წრფეზე დაშვებული მართობის სიგრძეა. მონაკვეთის **შუამართობი** მის შუაწერტილზე გავლებული მართობი წრფეა. კუთხის **ბისექტრისა** სხივია, რომელიც კუთხეს შუაზე ყოფს.</Definition>

<Formulas>
<Formula id="shortest-formula" name="მართობი და დახრილი" tex="PX^2 = PM^2 + MX^2 \;\Rightarrow\; PX > PM" live="PX" proof="perpendicular-shortest" />
<Formula id="perp-bisector-formula" name="შუამართობის წერტილი" tex="PM \perp AB,\ AM = MB \;\Rightarrow\; PA = PB" live="PA" proof="perp-bisector" />
<Formula id="bisector-formula" name="ბისექტრისის წერტილი" tex="\angle XOP = \angle POY \;\Rightarrow\; PK = PL" proof="bisector-equidistant" />
</Formulas>

<Properties>

<Property id="perpendicular-shortest" title="წერტილიდან წრფემდე გავლებულ მონაკვეთებს შორის უმოკლესი მართობია" why="ყოველი სხვა მონაკვეთი (დახრილი) მართკუთხა სამკუთხედის ჰიპოტენუზაა.">
<Proof given="$PM \perp AB$, $X$ — წრფის სხვა წერტილი" prove="$PX > PM$">
<Step show="PM PX X <PMB" hl="PMX" tex="PX^2 = PM^2 + MX^2">პითაგორას თეორემა მართკუთხა $\triangle PMX$-ში.</Step>
<Step hl="PM" tex="PX > PM \quad \blacksquare">$X \ne M$, ამიტომ $MX > 0$.</Step>
</Proof>
</Property>

<Property id="perp-bisector" title="შუამართობის ყოველი წერტილი მონაკვეთის ბოლოებიდან თანაბრადაა დაშორებული" why="შუამართობი მონაკვეთს ორ ტოლ მართკუთხა სამკუთხედად „ხედავს“.">
<Proof given="$P$ — $AB$-ს შუამართობის წერტილი" prove="$PA = PB$">
<Step show="PM <PMA" hl="AM=MB">$M$ — $AB$-ს შუაწერტილია და $PM \perp AB$.</Step>
<Step hl="PMA PMB" tex="\triangle PMA = \triangle PMB">$PM$ საერთოა, $AM = MB$, მათ შორის კუთხეები მართია — გკგ.</Step>
<Step hl="PA=PB" tex="PA = PB \quad \blacksquare">ტოლი სამკუთხედების შესაბამისი გვერდები.</Step>
</Proof>
</Property>

<Property id="perp-bisector-converse" kind="converse" title="მონაკვეთის ბოლოებიდან თანაბრად დაშორებული წერტილი მის შუამართობზე ძევს" why="ასეთი წერტილი ტოლფერდა სამკუთხედის წვეროა, მედიანა კი სიმაღლეც გამოდის.">
<Proof given="$PA = PB$" prove="$P$ ძევს $AB$-ს შუამართობზე">
<Step hl="PAB PA=PB">$\triangle PAB$ ტოლფერდაა.</Step>
<Step show="PM" hl="PM">$M$ — $AB$-ს შუაწერტილი, ამიტომ $PM$ ფუძეზე გავლებული მედიანაა.</Step>
<Step hl="<PMB">ტოლფერდა სამკუთხედში ფუძეზე გავლებული მედიანა სიმაღლეცაა: $PM \perp AB$, ე.ი. $PM$ შუამართობია. ∎</Step>
</Proof>
</Property>

<Remark>ამრიგად, შუამართობი მონაკვეთის ბოლოებიდან თანაბრად დაშორებული წერტილების სიმრავლეა (ამ წერტილთა გეომეტრიული ადგილი).</Remark>

<Property id="bisector-equidistant" title="კუთხის ბისექტრისის ყოველი წერტილი კუთხის გვერდებიდან თანაბრადაა დაშორებული" why="ორი მართკუთხა სამკუთხედი საერთო ჰიპოტენუზითა და ტოლი მახვილი კუთხით.">
<Proof figure="angle-bisector" given="$OP$ — $\angle XOY$-ის ბისექტრისა, $PK \perp OX$, $PL \perp OY$" prove="$PK = PL$">
<Step show="OP" hl="<XOP=<POY">$OP$ კუთხეს შუაზე ყოფს.</Step>
<Step show="PK PL K L <PKO <PLO" hl="OKP OLP" tex="\triangle OKP = \triangle OLP">მართკუთხა სამკუთხედები საერთო ჰიპოტენუზით $OP$ და ტოლი მახვილი კუთხეებით.</Step>
<Step hl="PK=PL" tex="PK = PL \quad \blacksquare">შესაბამისი კათეტები.</Step>
</Proof>
</Property>

<Property id="bisector-converse" kind="converse" title="კუთხის შიგნით მდებარე წერტილი, რომელიც გვერდებიდან თანაბრადაა დაშორებული, ბისექტრისაზე ძევს" why="იგივე ორი მართკუთხა სამკუთხედი, ოღონდ ჰიპოტენუზითა და კათეტით.">
<Proof figure="angle-bisector" given="$P$ კუთხის შიგნითაა, $PK \perp OX$, $PL \perp OY$, $PK = PL$" prove="$\angle XOP = \angle POY$">
<Step show="OP PK PL K L <PKO <PLO" hl="PK=PL">$P$-დან გვერდებამდე მანძილები ტოლია.</Step>
<Step hl="OKP OLP" tex="\triangle OKP = \triangle OLP">ჰიპოტენუზა $OP$ საერთოა, კათეტები $PK = PL$.</Step>
<Step hl="<XOP=<POY" tex="\angle KOP = \angle LOP \quad \blacksquare">შესაბამისი კუთხეები — $OP$ ბისექტრისაა.</Step>
</Proof>
</Property>

</Properties>

<Remark kind="mistake">მანძილი წერტილიდან წრფემდე მართობის სიგრძეა და არა ნებისმიერი მონაკვეთისა, რომელიც წერტილს წრფესთან აერთებს.</Remark>

<Problems>

<Problem id="p-perp-perimeter" set={{ c: 4, t: 2.6666666666666665 }} given="AB=12 P(ABP)=32" find="PA" answer="10" book="3.14"
  q="$P$ წერტილი $AB$ მონაკვეთის შუამართობზე ძევს. $ABP$ სამკუთხედის პერიმეტრი $32$-ია, $AB = 12$. იპოვეთ $PA$."
  hint="შუამართობის ნებისმიერი წერტილი მონაკვეთის ბოლოებიდან თანაბრადაა დაშორებული.">
<Step hl="PA=PB" tex="PA = PB">$P$ ძევს $AB$-ს შუამართობზე.</Step>
<Step hl="ABP" tex="2\,PA + 12 = 32 \;\Rightarrow\; PA = 10">ჩავწეროთ პერიმეტრი.</Step>
</Problem>

<Problem id="p-perp-in-triangle" figure="triangle" k={2.5} set={{ c: 5.2, b: 5.6, alpha: 43.27917520057224 }} show="BM" given="MA=MB P(BMC)=24 P(ABC)=37" find="AB" answer="13" book="3.11"
  q="$ABC$ სამკუთხედის $AB$ გვერდის შუამართობი $AC$ გვერდს $M$ წერტილში კვეთს. $ABC$ სამკუთხედის პერიმეტრი $37$-ია, $BMC$ სამკუთხედისა კი — $24$. იპოვეთ $AB$."
  hint="$MA = MB$ — ჩაწერეთ $BMC$ სამკუთხედის პერიმეტრი $AC$-სა და $BC$-ს საშუალებით.">
<Step hl="MA=MB" tex="MA = MB">$M$ ძევს $AB$-ს შუამართობზე.</Step>
<Step hl="BMC" tex="\begin{aligned}P_{BMC} &= MB + MC + BC \\ &= MA + MC + BC \\ &= AC + BC = 24\end{aligned}">ჩავსვათ $MB = MA$; $MA + MC = AC$.</Step>
<Step hl="AB" tex="AB = 37 - 24 = 13">დანარჩენი პერიმეტრი $AB$ გვერდზე მოდის.</Step>
</Problem>

<Problem id="p-bisector-30" figure="angle-bisector" set={{ phi: 60, d: 4 }} show="OP PK PL <PKO <PLO" given="<XOY=60 OP=12" find="PK" answer="6" book="4.17 4.20"
  q="$P$ წერტილი $60^\circ$-იანი კუთხის ბისექტრისაზე ძევს, წვეროდან $12$ სმ-ის მანძილზე. იპოვეთ მანძილი $P$ წერტილიდან კუთხის გვერდებამდე."
  hint="მართკუთხა სამკუთხედში $30^\circ$-იანი კუთხის პირდაპირ მდებარე კათეტი ჰიპოტენუზის ნახევარია.">
<Step hl="<KOP=<POL" tex="\angle KOP = \angle POL = 30^\circ">$OP$ ბისექტრისაა.</Step>
<Step hl="OKP <PKO" tex="PK = \tfrac12\, OP = 6">მართკუთხა სამკუთხედ $OKP$-ში $PK$ კათეტი $30^\circ$-იანი კუთხის პირდაპირ მდებარეობს.</Step>
<Step hl="PK=PL" tex="PL = PK = 6">ბისექტრისის ნებისმიერი წერტილი კუთხის გვერდებიდან თანაბრადაა დაშორებული.</Step>
</Problem>

<Problem id="p-bisector-quad" figure="angle-bisector" set={{ phi: 70, d: 3.6 }} show="PK PL <PKO <PLO" given="<KPL=110" find="<XOY" answer="70" book="4.14"
  q="$P$ წერტილიდან $XOY$ კუთხის გვერდებზე დაშვებულია $PK$ და $PL$ მართობები, $\angle KPL = 110^\circ$. იპოვეთ $\angle XOY$."
  hint="ოთხკუთხედის კუთხეების ჯამი $360^\circ$-ია.">
<Step hl="OKPL <PKO <PLO">ოთხკუთხედ $OKPL$-ში $K$ და $L$ კუთხეები მართია.</Step>
<Step hl="<XOY" tex="\angle XOY = 360^\circ - 90^\circ - 90^\circ - 110^\circ = 70^\circ">ოთხკუთხედის კუთხეების ჯამი $360^\circ$-ია.</Step>
</Problem>

  q="$P$ წერტილი $XOY$ კუთხის ბისექტრისაზე ძევს, $PK$ და $PL$ კი მართობებია კუთხის გვერდებზე. დაამტკიცეთ, რომ $OK = OL$."
  hint="შეადარეთ მართკუთხა სამკუთხედები $OKP$ და $OLP$.">
<Step hl="OKP OLP">$OKP$ და $OLP$ მართკუთხა სამკუთხედებია საერთო ჰიპოტენუზით $OP$.</Step>

<Step hl="OK=OL" tex="\triangle OKP = \triangle OLP \;\Rightarrow\; OK = OL \quad \blacksquare">მართკუთხა სამკუთხედები ტოლია ჰიპოტენუზითა და მახვილი კუთხით.</Step>
</Problem>
